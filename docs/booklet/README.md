# booklet/

This directory holds the *libretto layer* of Crystal Pool.

It is not specification.
It is not architecture.
It is not a manual.

The engineering documents (`docs/constitution.md`, `docs/architecture.md`) describe what the pool *does* and *will never do*.
The booklet describes what the pool *is for*, in a register a non-engineer can carry home.

Both layers are part of the same work. Neither replaces the other.

---

## Files

| File | What it is | Best read when |
|---|---|---|
| [`soulful-data.md`](./soulful-data.md) | Nine-movement bilingual libretto on hopepunk engineering ethics | First contact, or after a long day |
| [`three-panels.md`](./three-panels.md) | Triptych mapping the project's ethical, aesthetic, and philosophical lineages | When you want to know where this work stands in intellectual history |

The two files are a **warm/cool diptych**:
*Soulful Data* is meant to be **read aloud, inhabited, carried home**.
*Three Panels* is meant to be **looked at slowly, like three paintings**.
Neither replaces the other.

---

## On translation

Pieces in this directory are bilingual (中文 / English) by design.
Translation here is not duplication; it is *harmony*.
Sometimes Chinese leads, sometimes English leads.
Each language carries what the other cannot.

If you fork Crystal Pool into another language community, please treat the libretto as a *singable* document, not a string table.
