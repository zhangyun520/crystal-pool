## 不可妥协的约束

下面这些不是"建议"。是合同。违反 = 退回重写。

### 关于宪法的 5 条强制

1. **三货币防火墙是编译时不变量**。Signal/Tide/Reputation 用 branded types 实现：
   ```ts
   type Signal = number & { readonly __brand: 'signal' };
   type Tide = number & { readonly __brand: 'tide' };
   type Reputation = number & { readonly __brand: 'reputation' };
   ```
   任何函数尝试把 `Tide` 直接当 `Signal` 用，TypeScript 必须报错。
   运行时再有一道 `assertNoCrossCurrencyConversion()` 兜底。

2. **`/flow` 只能消费 `lib/meaning-clusters/*` 的输出**。不能直接 `import { prisma }`。这是分层守护。如果你发现自己想这样做，去补 Cluster Read Model，不要绕。

3. **任何系统消息禁止"诊断 + 处方"语态**。
   - ❌ "你看起来焦虑了"
   - ❌ "建议你休息一下"
   - ✅ "你这小时第 3 次对同一人 challenge 了"
   - ✅ "30 分钟后才发出，期间可撤回"
   写消息文案前先过 `tools/companion-tone-check/`（你也要顺便实现这个工具，作为 #23 Do No Harm Check 的一部分）。

4. **`crystallizationScore` / `cluster derivation` / `tempo vector` 三个函数纯 deterministic**。同输入同输出。禁止 `Date.now()`、`Math.random()`、`crypto.randomUUID()` 在这三个函数体内出现。如果需要时间，作为参数传入；需要随机数，用 hash-of-day 作为 seed。CI 里 grep 这三个文件，发现就退回。

5. **`PhaseEvent` / `ContributionEvent` / `ChainAnchor` 三张表 append-only**。不允许 update。不允许 delete。Prisma 操作只允许 `create`。如果业务需要"撤回"，那是另一个事件（recant），不是 update。

### 关于 ν / ρ 的 4 条强制

6. **`baseline_vega` 是私有字段**。永远不写到 actor profile 的公开返回值里。永远不参与全局训练。在 schema 中标记为 `@@unique([actorId])` 且 `select: { baselineVega: false }` 是默认的。

7. **Pool Phase 数据是 actor-anonymous 的**。Tempo Vector 6 维只读取聚合。永远不写 `Tempo` 数据时携带 `actorId`。Personal Pulse（v0.3）是另一回事 — 那时再说。

8. **Asymmetric Undo 的窗口是宪法级**。challenge 30 天，support 24 小时。这两个数字写在 `lib/contributions/effective-weight.ts` 顶部的常量。改动这两个常量需要走 #23 Do No Harm Check 流程。

9. **Sanctuary 期间的反对追溯免疫**：sanctuary 期内提交的 challenge，sanctuary 解除时**不自动应用**。它们落在 `requires_resubmission` 状态，等创建者主动确认后才生效。这是 ν-B5 的核心。

### 关于实现风格的 5 条强制

10. **每条核心机制都有单元测试覆盖它的宪法意图**。不只是 happy path。比如：
    - Three-Currency Firewall 测试：6 种跨货币转换，6 次抛错。
    - Asymmetric Undo 测试：challenge 第 31 天撤回必须失败。
    - The Body Knows 测试：连续 vetoBodyInference 10 次，对应 inference 的有效阈值降到 0。

11. **没有"以后再加注释"**。每个 deterministic 函数文件顶部必须有 `@deterministic` 标签 + 一句话写明它服从哪条宪法。

12. **Issue 顺序必须按依赖图执行**。`v0.1-issues.md` 给了关键路径。不要跳跃。

13. **每完成一个 issue，单独 commit**。commit message 格式：
    ```
    feat(scope): short description

    Closes #N.

    Constitution: §X.Y
    Architecture: Part X §N

    Signed-off-by: Pro Agent <pro@crystal-pool>
    ```
    `Signed-off-by` 是 DCO 必需。

14. **任何你觉得"应该灵活一下"的地方，停下来问**。Crystal Pool 的奇怪之处不是 bug，是核心。
