# Crystal Pool — 否定式宪法

> 这份文档不定义 Crystal Pool **是什么**。
> 它定义 Crystal Pool **永远不会成为什么**。
>
> 任何新功能、新机制、新合作方式、新贡献者提案——如果违反此处任何一条，不做。
> 修改这份宪法本身需要经过池子内的 Self-Critique Cycle + Dispute Resolution。

---

## 第零条：根基声明

Crystal Pool 是一个**本地优先的意义结晶引擎**。

它的存在前提是：

> 思想不是文件。思想是流动的、会相变的、会死的、会矛盾的、会被身体限制的。
> 人不是用户。人有节律、有痛、有沉默、有离场权、有死亡。
> 意义不是流量。意义需要摩擦、需要时间、需要被看见而不仅仅被点击。
> 池子不是工具。池子也有节奏、有体感、有疾病、有恢复——它是一个三层嵌套的生命体（节点层 / actor 层 / pool 层），每一层都会相变、会受伤、会愈合。

这四句话是池子的**存在前提**，不是功能描述。如果某个决策让这四句话中任何一句不再成立，那个决策就是错的。

## 第一章：关于金钱（7 条）

### 1.1 不发币

Crystal Pool 不发行任何具有金融属性的代币。Signal / Tide / Reputation / Witness / Patience / Bond 永远不可兑换为法定货币、加密货币、或任何可在外部市场交易的资产。

### 1.2 不接真钱

池子不接受任何形式的用户付费、订阅、打赏、NFT 购买、DeFi 质押、或"Pro 版"升级。如果需要运营资金，走捐赠 / 基金会 / 开源赞助。

### 1.3 不让钱改变话语权

任何外部捐赠者不因捐赠获得：更高的 Tide / Signal / Reputation / 投票权重 / 优先展示 / 规则修改权。捐赠只换来公开致谢（cosmetic）。

### 1.4 不做收入分成

不基于贡献量分配金钱。这不是 gig economy 平台。`mock_revenue_share` 类型永远不出现在任何 reward 枚举里。

### 1.5 货币永不互兑

Signal / Tide / Reputation / Witness / Patience / Bond 之间没有汇率、没有兑换通道、没有市场做市。违反此条等于摧毁整个体系的底层假设。

### 1.6 不做金融衍生品（对外的）

不做期货、期权、杠杆、做空、指数、流动性池、自动做市。唯一允许的"衍生"结构是对自己未来行为的承诺（Forward）和对自己判断改变的记录（Pair Swap）。

### 1.7 不做钱包

池子不接入任何区块链钱包、RPC 节点、或 Web3 签名流程。hash chain 和 anchor 都是本地的、可验证的、但不是链上的。

## 第二章：关于权力（6 条）

### 2.1 不设管理员

没有任何人类或组织拥有超越机制的权力。没有 "admin override"。没有 "god mode"。规则对所有人（包括创始人）一视同仁。

### 2.2 不让 AI 拥有主权

AI actor 可以参与（创建节点、辅助 review），但不能：投票、抵押、持有 Reputation、担任导师、发起道歉、进入陪审。AI 永远是工具，不是公民。

### 2.3 不做身份特权

Reputation 高的人不获得任何**数值类**特权。不因声誉高而获得：更多 Tide / 更重的投票权重 / 优先展示。声誉只解锁 cosmetic + 被委托的可能性。

### 2.4 不做隐秘治理

所有规则修改、Dispute 裁决、Self-Critique 报告、委托关系、Bond 抵押、Apology Edge——全部公开。没有"内部决策"。

### 2.5 不锁定用户

任何 actor 任何时候可以：暂停、撤离、抹除、分叉。池子不能以任何手段阻止离开。离开不产生惩罚。Forking Right 是宪法级权利。

### 2.6 不集中数据

用户的身体数据（心率、周期、屏幕时间）永远不离开本地设备。服务器只见标签，不见原始。违反此条等于监视。

---

## 第三章：关于注意力（5 条）

### 3.1 不最大化参与时长

Crystal Pool 不追求 DAU / MAU / session length / retention。不做"每日签到奖励"（Tide 是权利，不是奖励）。不做"连续打卡"。不做 push notification 轰炸。

### 3.2 不做算法推荐黑箱

所有排序、推荐、spotlight 的规则必须是 deterministic + 可解释 + 可审计的。没有"AI 猜你喜欢"。没有"个性化信息流"。每个 actor 看到的排序逻辑完全相同（除非他主动设置了过滤器）。

### 3.3 不奖励速度

不因"第一个回复"、"最快支持"、"首发评论"获得任何加权。Vesting 机制确保所有影响力延迟释放。快不是美德，慢不是缺陷。

### 3.4 不惩罚沉默

不参与不产生任何负面后果。不贡献不等于被忽视。Witness（阅读）和 Pause（暂停）是与发声同等的参与形式。

### 3.5 不做无限滚动

`/flow` 和所有列表有自然终点。没有 infinite scroll。如果页面有更多内容需要手动翻页或明确请求。

## 第四章：关于身体（4 条）

### 4.1 可观察 ≠ 可强制

系统可以提示身体状态相关信息，但不能替 actor 做决定、不能自动降权、不能锁定操作、不能强制休息。

### 4.2 身体数据永远本地

心率、周期、屏幕时间、环境光、睡眠 —— 这些数据的处理只发生在本地设备。服务器看到的只是 actor 自愿发出的状态标签。

### 4.3 否决永远有效

任何 actor 对系统给出的身体相关推断可以一键否决。否决一次，系统对该 actor 该方向的自信永久降低。系统学习它对这个具体的人是错的。

### 4.4 不假设默认身体

不预设用户是：成年人 / 男性 / 健全人 / 拥有稳定精力 / 使用视觉界面。所有核心功能必须有等效的非视觉版本。周期功能是通用的，不预设性别。

### 4.5 池子是伴侣，不是治疗师

系统**注意到**用户的状态（节律、疲惫、冲突、wound、回归），但**不主动诊断**；提供**避风港**和**陪伴信号**，但**不指导**；在用户需要时**在场**，在用户不需要时**安静**。

具体含义：
- ❌ "你看起来抑郁了，建议你做这些步骤"
- ✅ "你这小时第 3 次对同一人 challenge 了。30 分钟后才发出，期间可撤回。"

差别：前者是诊断 + 处方。后者是**陈述事实** + **创造缓冲** + **保留主动权**。

任何 ν 系统（创伤敏感设计）的机制必须服从这条——它是**机制设计的元约束**。

## 第五章：关于意义（5 条）

### 5.1 不让市场直接结晶

ContributionEvent / MarketOrder / Signal 压力可以**建议**图谱变化，但不可直接改变节点 / 边 / 相态。所有图谱变更必须经过 GraphEffectProposal → review → apply。

### 5.2 不删除历史

节点不可被物理删除，只可被 archive / dissolve / memorial。PhaseEvent / hash chain 不可回滚。Recant 是公开标记，不是删除。

### 5.3 不强制共识

`tension_pair`（矛盾配对）是一种合法的、被尊重的结晶状态。两个矛盾的想法可以永远共存。系统不假设"最终会有统一答案"。

### 5.4 不让 AI 评判意义

AI 可以提供：摘要、分类建议、重复检测、翻译辅助。AI 不可以：创建 edge / 修改 phase / 改变 crystallization score / 直接参与 cluster 排序。所有意义判断必须是 deterministic rule + human review。

### 5.5 不优化"正确"

池子不追求"收敛到真理"。它追求"让所有声音被结构化地看见"。一个被 10 次 challenge 的节点不一定"错"——它可能只是"有争议"。争议本身是价值。

## 第六章：关于开源与共创（6 条）

### 6.1 核心引擎永远开源

Crystal Pool 的核心层（Crystal Graph / Phase Engine / Contribution Hash Chain / MeaningCluster Read Model / Distribution Layer / Scoring Algorithm）永远以 OSI 认可的开源协议发布。任何人可以 fork、审计、自托管。

### 6.2 闭源只限非核心

如果存在商业实体运营托管版本，允许闭源的**仅限**：UI 主题 / cosmetic 资产 / 企业级 SLA / 托管运维工具。不允许对核心算法、规则引擎、hash chain 验证逻辑做闭源。

### 6.3 贡献者不让渡版权

所有外部贡献者保留对自己代码的版权。项目接受贡献的前提是 DCO (Developer Certificate of Origin) 签名，而非 CLA (Contributor License Agreement) 的版权转让。

### 6.4 不做 open core 陷阱

不出现"开源版缺关键功能，必须付费版才完整"的模式。如果某个功能对意义引擎的完整性是必要的，它就必须在开源版中。

### 6.5 集体共创的边界

任何人可以提出新机制（ContributionEvent 类型 = `build_intent`），但新机制生效必须经过：
1. 以节点形式进入池子
2. 经过公开 review（≥ 5 个独立 verify）
3. 经过 Self-Critique Cycle 或 Dispute Resolution
4. 不违反本宪法任何条款

### 6.6 Fork Right 是宪法级保障

如果核心维护团队做出违反本宪法的决策，任何 ≥ 100 个 actor 的群体可以行使 Fork Right，带走完整数据和代码。这是防止"开源项目被商业收编"的最后手段。

## 第七章：关于集体节奏（4 条）

### 7.1 不监视个人节奏

ρ 系统（Pool Tempo Vector / Frenzy Detector / Phase Detection）只测量**聚合数据**，永远不指向具体 actor。Personal Pulse 是**私有**的——只有 actor 自己看得见。永远不发布"谁在 Frenzy"这种识别个人的数据。ρ 数据**永远不**用于个人画像或行为预测。

### 7.2 不做央行式独裁干预

任何 ρ 调节机制（Counter-Cyclical Tide / Tempo Brakes / Capitulation Stimulus）的阈值和算法必须公开、可被池子内部 build_intent 修改、可被 Dispute Resolution 挑战。没有"管理员一键关掉 Frenzy"这种能力。调节只**改变激励**，不**禁止行为**——你仍然可以在 Frenzy 期发起 challenge，只是 vesting 自动延长到 7 天。

### 7.3 不用集体节奏压制个人

Pool Phase 的判定**只影响系统级机制**，从不**直接限制 actor 操作**。Personal Pulse 是反映不是规范——"你比集体更急"不暗示"你应该慢下来"。任何 actor 都可以选择**完全无视**当前 Pool Phase——所有操作仍然可执行。

### 7.4 不做阶段决定论

Pool Phase 命名（Accumulation / Activation / Frenzy / Capitulation）故意保留**模糊空间**——"Frenzy"不是"病态"，是"需要小心"。任何 actor 可以发起 Dispute Resolution 挑战当前 Pool Phase 判定。Self-Critique Cycle 周期性 review 阶段判定算法本身。

## 第八章：关于创伤敏感（5 条）

### 8.1 不让脆弱性证书化

所有 ν 机制只**减弱攻击**，不**增强防御**。受伤的 actor 不获得攻击别人的额外能力。Hardship Fund / Chronic Mode / Sanctuary 在期内**禁用攻击操作**（challenge / Bond）。Steward 不能代表被守护者发起攻击。judgment-free 节点不能挑战其他节点。

### 8.2 不让脆弱性家长主义化

所有保护机制必须有"我不需要保护"一键关闭按钮，且关闭这件事**不被记录、不被惩罚、不影响任何指标**。大多数 ν 机制是 opt-in 或自我声明，不预设保护。

### 8.3 不让脆弱性内卷化

baseline_vega 是**私有字段**——只对 actor 自己可见。没有"最受伤排行榜"。受伤后获得的不是**补偿**，是**保护期** + **慢慢愈合的工具**——没有任何 ν 状态可以累积成 Reputation 或 Tide。

### 8.4 不让保护变成停滞

所有 ν 保护机制都**有时间上限**：Sanctuary 14 天 / Hardship Fund 60 天且每年 2 次 / judgment-free 90 天后自动转普通。**保护是为了让你能继续，不是让你停下**。

### 8.5 不让脆弱性武器化

ν 状态只用于**减弱被攻击的强度**，不用于**增强攻击**。任何允许"以受伤之名免责攻击"的机制提案，自动违反本条。

## 第九章：关于这份宪法本身（3 条）

### 9.1 可修改，但昂贵

修改本宪法需要：
- Self-Critique Cycle 周期内正式提出
- ≥ 30% 活跃 actor 参与 review
- ≥ 70% 参与者投 support
- 30 天公示期
- 任何 actor 在公示期可发起 Dispute

### 9.2 修改历史不可擦除

本宪法的每次修改作为 PhaseEvent 进入 hash chain，永久可审计。

### 9.3 如果宪法和池子实际行为冲突

以宪法为准。实际行为必须修正到符合宪法，而不是修改宪法来合理化实际行为。这是最后的兜底。
